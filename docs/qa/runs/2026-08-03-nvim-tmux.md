## Defects

### P0 — Terminal Ctrl-C does not terminate workflow

Reproduction:

1. In tmux, run `dist/schlop --ui nvim file review.md`.
2. Press Ctrl-C while browsing.
3. Observe Neovim remains open and asks for `:qa`; launcher/controller remain alive.

Expected: launcher interruption is observed, termination reaches Neovim, exit is 130, and private files/processes are cleaned. The automated PTY test sends a signal directly to the launcher PID, so it did not cover the foreground terminal signal behavior exercised here.

### P1 — Composer save leaks Insert mode into immutable content

After `c`, body entry, and `Ctrl-s`, the float closes and annotation persists, but the restored content window remains in Insert mode. A subsequent `s` attempts to modify the readonly buffer and raises E21 instead of submitting. The user must press Escape manually.

### P1 — Editing does not safely replace selected body

The edit composer visually selected `Original note`, but normal replacement interaction with Ctrl-U and typed text yielded `Edited noteOriginal note`. Editing needs deterministic select-all/replacement behavior or documented composer commands.

### P1 — Live resize does not recompute pane layout

A session opened wide retains its sidebar after shrinking to 68 columns. The sidebar collapses to a mostly blank sliver while status text truncates. Fresh narrow launch correctly uses a single pane, so the missing behavior is reactive layout recomputation.

### Compatibility finding — normal user config can block Schlop startup

The operator's actual config loaded as requested, including theme and plugins. Its treesitter installer attempted to invoke a missing external `tree-sitter` command and emitted recurring `Press ENTER` errors over Schlop. This is user-config behavior rather than inspected-content execution, but CLI mode currently has no containment or compatibility warning because loading normal config is intentional.

### P2 — Help/sidebar text truncation

At wide width, the final help sentence displayed truncation markers; at narrow width, the context-side mapping wrapped awkwardly. Sidebar action text also wraps (`cancel`) at normal widths.

## Recommendation

Do not declare the Neovim flavor interactively complete until:

1. foreground-terminal Ctrl-C exits with cleanup and has a tmux regression test;
2. composer save explicitly leaves Insert mode before restoring the content window;
3. edit composer replacement is deterministic and tested through real keys;
4. resize events add/remove or rebuild the sidebar at the documented breakpoint.

After fixes, rerun NV-04, NV-05, NV-08, and NV-12 first, then repeat the entire P0 matrix.
